# Development Roadmap

## Stage 1: Environment and setup

- Verify Node, npm, Python, Git, and PostgreSQL availability
- Confirm project workspace status
- Establish the foundations for frontend and backend development

## Stage 2: Project scaffolding

- Create the Next.js frontend
- Create the Django backend and modular app structure
- Establish environment configuration and repository hygiene

## Stage 3: Design system

- Add a professional color palette and spacing approach
- Create a responsive layout model for desktop and mobile users

## Stage 4: Core UI layout

- Build the main navigation, top bar, and page shells
- Create a clean dashboard layout with working cards and data sections

## Stage 5: Dashboard

- Expose summary data from backend reporting endpoints
- Add date filters and business filters

## Stage 6: Business management

- Create, list, edit, and activate/deactivate businesses
- Add validation and reusable forms

## Stage 7: Customer management

- Create, list, search, and filter customers
- Enforce business-customer association rules

## Stage 8: Document architecture

- Implement quotation, invoice, and receipt records
- Add numbering rules and line-item support

## Stage 9: API and validation

- Strengthen serializer and view validation
- Enforce backend relationships and protections

## Stage 10: Verification

- Run linting, type checks, Django tests, and backend validation
- Fix issues and document the current state honestly
